# Takeer — Social Commerce Platform

## Project Overview
Takeer is a social-commerce platform operated by **AVLY TECH GROUP LIMITED**. It combines social media features with e-commerce functionality, enabling merchants to sell through live-stream shopping, influencer marketing, and social interactions.

This project is located at `~/Projects/Takeer_revised`.

## Key Business Context
- **Company**: AVLY TECH GROUP LIMITED — a multi-line technology company
- **Business Lines**: Computer Consultancy, Software Engineering, Data & Infrastructure, Digital Commerce, Specialized IT Services, Advertising & Digital Marketing, Cross-Sector Tech
- **Takeer (= THIS PROJECT)**: The flagship social-commerce platform connecting Digital Commerce + Advertising + Software Engineering
